DE CRM — Quick Reference
========================

REPO LAYOUT
-----------
  web/      Next.js 15 frontend, port 3000
  api/      Node + Express + Drizzle backend, port 4000
  project docs/   architecture, data model, build plan
  Digital Edify Agentic CRM (standalone).html   original Subframe design


FIRST-TIME SETUP (already done — skip unless on a fresh machine)
----------------------------------------------------------------
  cd web && npm install
  cd ../api && npm install
  copy api\.env.example api\.env       # then edit .env, fill passwords
  cd api && npm run db:migrate         # creates 21 tables on Azure
  cd api && npm run db:seed            # loads tenant + 12 leads + agents


RUN LOCALLY (every day)
-----------------------
  Terminal 1 — frontend:
    cd web && npm run dev              # http://localhost:3000

  Terminal 2 — backend:
    cd api && npm run dev              # http://localhost:4000/health

  (Optional) Terminal 3 — DB browser:
    cd api && npx drizzle-kit studio   # https://local.drizzle.studio


DB COMMANDS (run from api/)
---------------------------
  npm run db:check     ping Azure + list installed extensions
  npm run db:migrate   apply pending schema changes
  npm run db:seed      reset tenant data + reload all rows (idempotent)
  npm run db:reset     drop public schema. Then migrate + seed.


EDITING THE SCHEMA
------------------
  1. Edit api/src/db/schema.ts
  2. cd api && npx drizzle-kit generate   # writes new SQL into drizzle/
  3. npm run db:migrate                   # applies it


AZURE DATABASE
--------------
  Server:    de-crm-pg.postgres.database.azure.com
  Region:    Central India
  Version:   PostgreSQL 17, Burstable B1ms (~$15/mo)
  Extensions enabled: pgcrypto, pg_trgm, vector
  Tables:    21 (full doc-03 model)

  Two roles (passwords in api/.env, NOT api/.env.example):
    decrm_admin   migrations + seed only (bypasses RLS — Azure default)
    decrm_app     the API connects as this role (NOBYPASSRLS, RLS enforced)

  Common gotcha: home Wi-Fi public IP changes, breaking the firewall rule.
  Fix: Azure Portal → de-crm-pg → Networking → "+ Add current client IP"
       → Save (button at top, not just the +Add).

QUICK TROUBLESHOOTING
---------------------
  "ETIMEDOUT 5432"           public IP rotated. Re-add IP in Azure Networking.
  "type vector does not exist"   extension allowlist not saved. Server params → azure.extensions.
  ".env not loading"         confirm api/.env exists (not just .env.example).
  "drizzle studio: schema not found"   run `npm run db:migrate` first.
